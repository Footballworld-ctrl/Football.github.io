예제 8-10. 이벤트 함수

버튼을 클릭하면 연결된 JavaScript 함수가 실행됩니다.

버튼을 누르면 이곳에 결과가 표시됩니다.

설명: onclick은 버튼을 클릭했을 때 실행할 동작을 지정합니다. showMessage()는 실행할 함수의 이름입니다. document.getElementById()는 id가 eventResult인 HTML 요소를 찾고, textContent는 그 요소의 글자를 바꿉니다.

합계: 아직 계산하지 않았습니다.

예제 8-12. 내장 함수 prompt(), confirm(), alert()

각 버튼을 눌러 세 가지 내장 함수의 차이를 확인하세요.

내장 함수 실행 결과가 이곳에 표시됩니다.

설명: prompt()는 글자를 입력받는 창을 띄웁니다. confirm()은 확인과 취소를 선택하는 창을 띄우며, 확인하면 true, 취소하면 false를 돌려줍니다. alert()은 메시지를 보여주는 창을 띄웁니다.
